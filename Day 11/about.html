About This Project

A Flask-based student management system built as a demo project.

🎯

Project Goal

This application demonstrates a full-stack web application using Flask. It includes routing, templating with Jinja2, form handling, and a professional UI — showcasing core Flask development skills.

🗄️

Dataset

The dummy data is inspired by the Student Performance Dataset (student-mat.csv) which contains 395 records of secondary school students, including grades (G1, G2, G3), demographics, and study habits.

🛠️

Tech Stack

  • 🐍 Python 3
  • 🌐 Flask (micro web framework)
  • 🎨 HTML5 + CSS3
  • 📄 Jinja2 Templating
📁
